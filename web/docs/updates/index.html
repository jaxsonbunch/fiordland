Updates

Fiordland is a rolling release. Packages update in small steps, and new releases arrive the same way.

Update

tawaki update

Run it every week or two. It counts what is waiting in each source, asks before it starts, then updates the system with pacman -Syu, then AUR packages, then Flatpaks. To look without installing anything, run tawaki check.

The Kuaka update app does the same with a window. It groups updates, marks the ones that need a restart, shows release notes and Arch news, and has a history tab with an Undo button for every snapshot taken before a change. With kuaka --tray it checks in the background every 6 hours by default and notifies at most once a day.

Channels

Arch packages arrive through one of two channels. Stable is a snapshot of the Arch repos that moves forward every two weeks, after Fiordland's install, update and boot tests pass, and security fixes arrive sooner. Rolling gets packages the day Arch releases them, which is newer and less tested. Stable is the default.

fiordland-channel
fiordland-channel rolling
fiordland-channel stable

Without an argument it prints the current channel. With one it switches, then run tawaki update to sync.

New releases

A new ISO is only for new installs. An installed system gets the same changes through tawaki update: new default packages, settings and fixes ship as numbered migrations in fiordland-base. Each runs once, after the pre update snapshot, and is written to be safe to run twice. When the release number changes, the update prints it with a short list of what is new, for example Fiordland 0.9.0 -> 1.0.0.

  • fiordland version shows the current release, and fiordland news shows the notes. cat /etc/os-release works too.
  • fiordland-migrate --list shows which release changes are applied.
  • A change that fails is reported, logged in /var/log/fiordland-migrate.log and tried again on the next update.
  • All release notes are on the news page.

Before updating

  • Close games and apps that are running, and keep a laptop plugged in.
  • Read what the update prints. Messages that start with ==> or warning: sometimes ask you to do something.
  • Updates to the kernel, firmware, systemd, glibc, Mesa and NVIDIA drivers need a restart to take effect. Until then, new USB devices and some drivers may not load.

When an update goes wrong

A snapshot is taken before every update, so you can go back. See snapshots and rollback. If the desktop does not start, pick the Arch kernel or safe graphics in the boot menu first, or boot an older snapshot from the Fiordland snapshots entry. Each snapshot includes its own kernel, so this also undoes a bad kernel update.

Clean up

Old package downloads are cleared every week automatically, keeping the last three versions. To remove packages nothing uses any more:

sudo pacman -Rns $(pacman -Qdtq)

Snapshots from updates are trimmed to the newest 10, and Btrfs is scrubbed monthly.
