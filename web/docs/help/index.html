Getting help

Where to ask, what to include, and how to collect it.

Where to ask

  • Wiki: guides and fixes written by users. Search it first, especially the Troubleshooting and FAQ pages.
  • Help desk: ask a question on the wiki. Every wiki page also has a Discussion tab.
  • Discord: chat with other users. Run /helpme to see what to include.
  • GitHub issues: bugs in Fiordland, tawaki or the installer, with a form for bug reports, feature requests and hardware reports.
  • Arch Wiki: Fiordland uses the Arch repos, so most of it applies.

What to include

What you did, what you expected, and what happened instead. The exact error text, copied rather than retyped. Your hardware, especially the GPU.

Fiordland can collect the details for you. This writes one file in your home folder with your user and host names replaced, and nothing is uploaded:

fiordland report

To print a hardware summary you can paste, or the errors from the current boot:

inxi -Fxz
journalctl -b -p err --no-pager | tail -50

If the installer fails

Press Save log on the failure page, then try again from the Review page. Attach the log to a bug report. Other install problems are covered at the end of the install guide.

Do not paste

Passwords, WiFi keys or anything from /etc/shadow. inxi -z already hides serial numbers and IP addresses. For a security problem, do not open a public issue: follow the security policy.
