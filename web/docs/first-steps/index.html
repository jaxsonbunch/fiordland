First steps

What to do after the first boot, and what Fiordland has already done for you.

Connect to the internet

Click the network icon in the panel and pick your WiFi. A cable works without any setup.

Update once

The ISO may be a few days old. Open a terminal and run:

tawaki update

It asks for your password, then updates the system, AUR packages and Flatpaks together. If the Fiordland release number changes, it prints it with the release notes. Close games and apps first, and restart afterwards if the kernel was updated.

Install your apps

Use tawaki from the terminal. It finds the cleanest source for each app, and i is a shortcut for install:

tawaki install firefox steam discord

The apps guide covers search, removing, sources and settings. Flathub is already set up, so Flatpak apps work straight away.

Already set up for you

  • Graphics drivers for your GPU, Vulkan, and 32 bit libraries for Steam and Wine.
  • Steam, the CachyOS builds of Proton and Wine, umu launcher, gamemode, MangoHud and gamescope. Remove them with sudo pacman -Rns fiordland-gaming if you do not play.
  • Btrfs with automatic snapshots before every update, so a bad update can be undone.
  • Printing with network printers found automatically, Bluetooth, power profiles, firmware updates and zram swap.
  • A firewall (ufw) that blocks incoming connections, and encrypted DNS one command away with sudo fiordland dns tls.
  • GRUB, with other systems found by os-prober. On a dual boot, the menu lists both Fiordland and Windows.

Pair Bluetooth devices

On the crest desktop, open quick settings and click the arrow on the Bluetooth tile. Put the device in pairing mode and click it under available. If it shows a code or needs a PIN, crest asks for it. Other desktops have their own Bluetooth settings.

Make it yours

  • Change desktop. Open Desktops (weka) to add, remove or swap desktops and window managers without reinstalling.
  • Choose a kernel. The CachyOS kernel is the default and the Arch kernel stays as a backup. To try the Fiordland kernel, run sudo fiordland kernel fiord.
  • Pick a channel. Stable is the default. fiordland-channel rolling gets packages the day Arch releases them.
  • Tune for the machine. Fiordland picks lighter settings on weak hardware by itself. fiordland-tune status shows what is in use, and sudo fiordland-tune apply low-end, balanced or performance chooses by hand.
  • Live wallpapers. If you own Wallpaper Engine on Steam, Kereru plays your wallpapers.

Terminal basics

  • sudo runs a command as administrator. It asks for your own password.
  • Typing a command you do not have tells you which package provides it.
  • Ctrl+C stops a running command. Ctrl+Shift+V pastes in most terminals.
  • fiordland version shows your release, and fiordland news shows what changed.
