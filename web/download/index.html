Download Fiordland Linux

The ISO boots a live KDE Plasma session and starts the installer. You can try Fiordland before anything is written to your disks.

Packages and the repository database are signed. The signing key is 11DC 7CDC CFD3 CB71 196E BEF1 FD69 DE77 164F 4200, and the security page explains how it is used.

What you need

ProcessorAny 64 bit x86 PC. UEFI is recommended, older BIOS machines work too.
Memory4 GB at least, 8 GB or more is better.
Disk30 GB, either a whole disk (which is erased) or free room next to Windows on a UEFI computer.
USB stick4 GB or more.
NetworkAn internet connection during the install. Packages are downloaded fresh, so you get current software.
Secure BootTurn it off in the firmware settings first. Fiordland's boot files are not signed yet.

Back up anything you want to keep before you start. Installing on a whole disk removes everything on it.

Four steps to a working desktop

  1. Write the ISO to a USB stick with Rufus in DD image mode, balenaEtcher, or dd on Linux.
  2. Boot from the stick. Open the boot menu while the logo shows (usually F12, F11, F8, Esc or F2) and pick Fiordland Linux live.
  3. Try it first if you like. The live session runs KDE Plasma and starts the installer by itself. You are logged in as fiord with no password, and nothing is written to your disks until you press Install on the Review page.
  4. Install. Work through five pages: region, disk, account, desktop and review. It takes 5 to 20 minutes depending on your connection.

The install guide covers every page of the installer, installing next to Windows, and what to do if the disk does not show up.

Other ways to get it

  • Mirrors carry the ISO and the package repository, and you can host one yourself.
  • In the Discord, run /iso for the latest link and checksum.
  • Installed systems use the package repository at https://fiordlandlinux.org/repo/x86_64. Browse it.
  • An installed system does not need a newer ISO: updates bring the same changes.
