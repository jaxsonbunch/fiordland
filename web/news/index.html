News

What changed in each Fiordland release. Installed systems get these with tawaki update.

Fiordland 1

26 November 2026 · plain text

  • Fiordland is out of beta. Installed systems move to Fiordland 1 with a normal update; nothing needs reinstalling.
  • New linux-fiord kernel, our fork of the CachyOS kernel with BORE, built for the x86_64 baseline so it also runs on older CPUs. Pick it in the installer or switch with sudo fiordland kernel fiord.
  • crest 1, a new Hyprland shell in the Material 3 Expressive style, with crest-greeter as its login screen.
  • tawaki 1.0, kuaka 1.0 and weka 1.1: one command for the Arch repos, Flathub and the AUR, a redesigned update manager with tray notices, and a redesigned desktop switcher.
  • The rawaru installer 2.0 is redesigned, checks your disk and settings before it starts, and has a Low end PC switch.
  • Restarting and shutting down no longer hang. Services get 10 seconds to stop (your own apps 5), and if something still blocks, the system restarts anyway after 3 minutes instead of waiting forever.
  • Faster start: the boot no longer waits for the network, and the Btrfs snapshot watcher and mirror refresh run in the background.
  • New fiordland-tune picks lighter settings on its own on PCs with less than 4 GB of memory, two CPU threads or no graphics acceleration. Switch by hand with sudo fiordland-tune apply low-end, balanced or performance. Try the sched_ext schedulers with sudo fiordland-tune scx lavd (needs scx-scheds).
  • One front door: fiordland version, news, tune, report, channel, kernel and dns. fiordland report collects details for a bug report; nothing is uploaded.
  • Now included: firewall on by default, printing with network printer discovery, Bluetooth, firmware updates (fwupd), disk health tools, CJK and emoji fonts, audio and video codecs with hardware decoding, plocate, and monthly Btrfs scrubs. Snapshots from updates are trimmed to the newest 10.
  • Optional: encrypted DNS with sudo fiordland dns tls and a Btrfs swap file with sudo fiordland-tune swapfile 8.
  • Updated install image 2026.11.26 build 3: the installer asks you to join WiFi before it starts, retries slow downloads, and the crest lock screen accepts your password every time.

Fiordland 0.9.1

24 November 2026 · plain text

  • New stable channel: Arch packages now come from a tested snapshot that moves forward every two weeks, after install, update and boot tests pass. Security fixes arrive sooner. To get packages the day Arch releases them instead: fiordland-channel rolling
  • The installer cleans up when you press Try again, and shows the reason when something fails.
  • Gaming packages: Steam, proton-cachyos, wine-cachyos, umu-launcher, protontricks, gamemode, MangoHud and gamescope now come with Fiordland and install in the background after this update. To remove them: sudo pacman -Rns fiordland-gaming

Fiordland 0.9.0, the public beta.

24 November 2026 · plain text

  • Updates now carry system changes too: run tawaki update and your install keeps up with new ISOs. No reinstall needed.
  • New installs use GRUB: older snapshots can be started from the boot menu, and sudo fiordland-rollback makes one permanent.
  • The installer can put Fiordland next to Windows or on partitions you choose.
