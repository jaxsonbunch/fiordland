Software

The parts Fiordland is made of, with their versions, languages, source and documentation.

Applications

tawaki

Package manager1.0.2

Installs, removes, searches and updates software from pacman, Flathub and the AUR with one command, picking the cleanest source. Looks in all three at once and warns before building from the AUR.

RustSourceDocumentation

rawaru

Installer2.0.7

The graphical installer on the live ISO. Whole disk, next to Windows or your own partitions, Btrfs with snapshots, GRUB on UEFI and BIOS, GPU driver detection and a choice of 11 desktops and 13 window managers.

Python, PySide6 and QMLSourceDocumentation

kuaka

Update app1.0.2

Shows what is waiting, updates system packages and Flatpaks in one click, marks updates that need a restart, and undoes an update from its history tab through snapshots.

Rust and SlintSourceDocumentation

weka

Desktops app1.1.1

Adds, removes and swaps desktops and window managers, sets up the login manager and removes what the old one left behind.

Python, PySide6 and QMLSourceDocumentation

crest

Desktop shell1.0.1

The Hyprland shell: bar, launcher, notifications, dashboard, quick settings, lock screen, overview and settings, in plain QML with no C++ plugin. Includes the greetd login screen, crest greeter.

QML on QuickshellSourceDocumentation

Kereru

Live wallpapers0.1.0

An optional extra that plays Wallpaper Engine wallpapers you own on Steam, with a picker, a tray icon and a sandboxed engine.

Rust and SlintSourceDocumentation

System packages

The Fiordland kernel

Kernel7.3.6

A fork of the CachyOS kernel packaging with the BORE scheduler, a 1000 Hz timer, BBRv3 and NTSYNC built in, targeting the x86_64 baseline so it runs on older CPUs.

Arch packageSourceDocumentation

fiordland base

Release and migrations1.0.0

The release itself: core packages, the fiordland command, release notes and numbered system migrations that bring installed systems up to date without a reinstall.

Arch packageSourceDocumentation

fiordland tune

Hardware profiles1.0.0

Picks low end, balanced or performance settings by itself from the memory, CPU threads and graphics of the machine, and lets you choose by hand.

Arch packageSourceDocumentation

fiordland desktop

Defaults and branding1.0

Desktop defaults and branding for Fiordland.

Arch packageSource

fiordland gaming

Gaming packages1.0

A meta package: Steam, the CachyOS builds of Proton and Wine, umu launcher, protontricks, winetricks, gamemode, MangoHud and gamescope. Remove it in one command if you do not play.

Arch packageSourceDocumentation

fiordland dev

Developer tools1.0

An opt in meta package for programming: base-devel, git, github-cli, cmake, meson, clang, gdb, Python with pip, Node.js, Go, OpenJDK, podman and more. Install it with tawaki install fiordland-dev.

Arch packageSource

fiordland keyring

Signing key1

The public key that every package and the repository database are signed with.

Arch packageSourceDocumentation

Licenses and source

Fiordland's own software is licensed GPL 3.0. The kernel and other upstream software keep their own licenses. The main repository holds crest, the packaging, the ISO profile, the website and the build tools. tawaki, rawaru, kuaka and weka live in their own repositories under the Fiordland Linux organization on GitHub, and the main repository packages their tagged releases. Versions above are read from the package build files, so they match what is in the repo.

Desktops and window managers

The installer offers 11 desktops: KDE Plasma (the default), GNOME, COSMIC, Xfce, Cinnamon, Budgie, MATE, LXQt, Deepin, Enlightenment and LXDE. It offers 13 window managers: Hyprland, niri, Sway, labwc, i3, bspwm, awesome, Qtile, xmonad, herbstluftwm, Openbox, Fluxbox and IceWM.

Some choices offer dotfile sets that bring their own setup: the Fiordland shell (crest), Noctalia, Dux Shell, Caelestia, illogical impulse, HyDE, ML4W, JaKooLit and iNiR.
