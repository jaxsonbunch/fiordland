About Fiordland

A distribution based on Arch, made in the open, with its own installer, package manager, update app and desktop shell.

What Fiordland is

Fiordland Linux is a Linux distribution based on Arch Linux. It installs a complete desktop in a few clicks, keeps itself current with a tested stable channel, and takes a Btrfs snapshot before every update so a bad one can be undone. The installer, the package manager, the update app and the desktop shell are all written for Fiordland rather than borrowed.

It is aimed at people who want Arch packages and a fast kernel without assembling the system by hand: new Linux users coming from Windows, gamers, and anyone with an older machine that deserves a second life. The same install adapts to the hardware it lands on.

The name and the logo

The Fiordland penguin, called tawaki in Maori, is a crested penguin that lives in the rainforests of the south west of New Zealand. The logo is a tawaki: the yellow stripe is its crest and the terminal prompt is its eye.

History

  1. 24 November 2026
    Fiordland 0.9.0, the public beta.

    Updates carry system changes, so an install keeps up with new ISOs. New installs use GRUB with snapshots you can boot, and the installer can put Fiordland next to Windows.

  2. 24 November 2026
    Fiordland 0.9.1

    A tested stable channel, gaming packages that come with Fiordland, and an installer that cleans up and shows the reason when something fails.

  3. 26 November 2026
    Fiordland 1

    Out of beta, with the Fiordland kernel, crest 1, tawaki 1.0, Kuaka 1.0, weka 1.1, a redesigned installer, faster boot, shutdowns that no longer hang and automatic tuning for weak hardware.

Fiordland 1 is the first release out of beta. Installed systems move to it with a normal update, and nothing needs reinstalling. Read the full release notes.

What it is made of

PartRoleWhat it does
tawakipackage managerInstalls, removes and updates software from pacman, Flathub and the AUR with one command.
rawaruinstallerA graphical installer with 11 desktops, 13 window managers, Btrfs and dual boot with Windows.
crestdesktop shellThe Hyprland shell, written in plain QML for Quickshell.
Kuakaupdate appShows pending updates, applies them in one click and puts the system back to a snapshot if one goes wrong.
wekaDesktops appAdds, removes and swaps desktops and window managers cleanly, without reinstalling.
The Fiordland kernelkernelA fork of the CachyOS kernel packaging with the BORE scheduler and BBRv3, built for the x86_64 baseline so it runs on any 64 bit CPU.

The software page has versions, languages and source links for every part.

Who makes it

Fiordland Linux was created by Apollo (3cfl on GitHub, u5sk on Discord), who designs and maintains it, with help from the contributors listed on GitHub. It is developed in the open: every package, the installer, the website and the build scripts live in the Fiordland repository, and the license is GPL 3.0. See how to contribute if you want to help. The website was designed by taz (jaxsonbunch on GitHub).

Built on the work of others

  • Arch Linux and its package repositories, the base of everything.
  • CachyOS, whose kernel packaging the Fiordland kernel is forked from, and whose Proton and Wine builds ship in the gaming package.
  • Quickshell by outfoxxed and contributors, which crest is built on. crest 1 draws on the Hyprland dotfiles by end 4, and the earlier crest was forked from Caelestia shell. Both are GPL 3.0.
  • archiso, the base of the live ISO.
  • The maintainers of the AUR packages bundled in the repository.

Contact

For bugs and ideas, use GitHub issues. For questions, the Discord and the wiki help desk are the fastest. For anything else, write to fiordlandlinux@gmail.com. Security problems go through the security policy.

Questions?
