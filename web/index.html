Fiordland Linux

Based on Arch, with its own installer, package manager and desktop shell. Its own kernel built on CachyOS, Btrfs snapshots and Flathub set up from the start. Steam, MangoHud and gamescope come installed.

DownloadWhy Fiordland

x86_64 · about 3 GB

What is inside

Fiordland ships its own installer, package manager and shell. Pick a part to see it.

tawaki install firefox steam
tawaki search obs
tawaki update
tawaki install foo --from aur

Packages are looked up in all three sources at once. A prebuilt package is preferred over a Flatpak that would pull in a large runtime you do not have yet.

Fiordland 1

26 November 2026

Read the release notes
  • Fiordland is out of beta. Installed systems move to Fiordland 1 with a normal update; nothing needs reinstalling.
  • New linux-fiord kernel, our fork of the CachyOS kernel with BORE, built for the x86_64 baseline so it also runs on older CPUs. Pick it in the installer or switch with sudo fiordland kernel fiord.
  • crest 1, a new Hyprland shell in the Material 3 Expressive style, with crest-greeter as its login screen.
  • tawaki 1.0, kuaka 1.0 and weka 1.1: one command for the Arch repos, Flathub and the AUR, a redesigned update manager with tray notices, and a redesigned desktop switcher.
