Mirrors

Servers that carry the package repo and the ISOs. Packages are signed, so a mirror can't change one without pacman noticing.

Loading mirrors..

Status is checked every 10 minutes. A mirror is marked down if it is unreachable or more than 6 hours behind.

Use a mirror

Installed systems use the primary server. To switch, change the [fiordland] section in /etc/pacman.conf:

[fiordland]
SigLevel = Required
Server = https://MIRROR/repo/$arch

A list of the mirrors that are up right now is at /mirrors/mirrorlist.

Host a mirror

You need enough disk for all files listed in the current mirror manifest, plus room for a new ISO, a hostname with HTTPS, and a connection that can handle ISO downloads of 3 GB each. Sync once an hour.

  1. Get the script

    curl -O https://fiordlandlinux.org/mirrors/sync.sh

  2. Run the first sync

    bash sync.sh /srv/mirror/fiordland

    It downloads the repo and ISOs, checks every file against a SHA256 manifest, and removes files the primary no longer has.

  3. Sync every hour

    0 * * * * /bin/bash /path/to/sync.sh /srv/mirror/fiordland

  4. Serve it over HTTPS

    mirror.example.org {
    root * /srv/mirror/fiordland
    file_server
}

    The site root must contain repo/ and iso/.

  5. Tell us

    Open an issue on GitHub with the URL, your location and the name to show as sponsor. We add it to the list once it passes the check.

Verify downloads

The SHA256 for the latest ISO is on the download page and in the mirror's iso/latest.json. Compare it after downloading from any mirror.
